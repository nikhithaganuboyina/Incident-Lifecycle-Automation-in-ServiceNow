# Incident Lifecycle Automation in ServiceNow

## Project Overview

This project automates the complete **Incident Management lifecycle** in ServiceNow, from incident creation to resolution and closure.

## Objectives

* Automate incident creation and classification
* Automatically assign incidents to support teams
* Set priority based on Impact and Urgency
* Monitor SLAs and handle escalations
* Automate notifications and status updates
* Maintain incident history and resolution details
* Generate reports for incident tracking

## Incident Lifecycle

**New → Assigned → In Progress → On Hold → Resolved → Closed**

## Key Features

## Project Workflow

1. Create an incident.
2. Classify the incident using category, subcategory, impact and urgency.
3. Automatically determine priority.
4. Assign the incident to the appropriate support group.
5. Use Knowledge Articles to assist with resolution.
6. Escalate the incident to Level 2 support when required.
7. Create an emergency change if necessary.
8. Create child incidents for related issues.
9. Document the cause and resolution.
10. Resolve and close the incident.
11. Track SLA and related records.

## Expected Outcome

The system reduces manual effort, improves incident resolution time, supports SLA compliance, and provides better visibility into the complete incident lifecycle.

## Conclusion

The project demonstrates how ServiceNow can be used to automate **Incident Management** and integrate Incident, Change, Knowledge, SLA, and reporting processes into a structured workflow.
